# Спецификация iOS-клиента

Клиент позволяет выбрать DICOM-серию, передать её Backend и получить результат локализации ВНЧС.
Нормативные требования описывают желаемое наблюдаемое поведение; наличие требования не означает его реализации.
Технические особенности текущего клиента и основания оценки вынесены в [документацию реализации](../ai/README.md).

## Границы

В этом контракте результат анализа — числовая локализация левого и правого ВНЧС с размером объёма, если эти данные предоставлены.
Выбор пользователем серии разрешает её отправку в предусмотренный Backend после явного запуска анализа.
Клиент не получает права на произвольные файлы устройства или другую серию.

Классификация положения, сегментация и клинический диагноз не входят в действующий сценарий.
Просмотр DICOM и наложение локализации на изображение также не входят в этот контракт.
Наличие отдельных моделей данных или компонентов не расширяет продуктовые обязательства.

## Как читать

`FR-IOS-*` и `NFR-IOS-*` — устойчивые требования; `TC-IOS-*` — критерии приёмки.
`GAP-IOS-*` означает известное расхождение с требованием.
`OQ-IOS-*` означает вопрос, для которого ещё нет согласованного правила.
Приёмка проверяет поведение; ссылка на исходник подтверждает только статическую оценку реализации.

Общие правила: [конституция](../../../docs/spec/constitution/README.md), [соглашения](../../../docs/spec/conventions/README.md), [глоссарий](../../../docs/spec/glossary/README.md).
Общие границы системы заданы в [интеграционном контракте](../../../docs/spec/integration/README.md).
