## Как прошло обучение

1. **Ранние эпохи (коллапс по порогу 0.5).** Эпоха 1: на val модель предсказывала почти всё как «нецентральное» (sensitivity 1.0, specificity 0.0 при пороге 0.5). Эпоха 2: обратный край — всё «центральное» (sensitivity 0, specificity 1.0). Это типичная нестабильность при **малом val (30)** и **8** примерах класса 1, а не обязательно ошибка в коде.

2. **Плато по AUC около эпох 11–12.** `val_auc` достигает **~0.699** и дальше не улучшается; срабатывает ранняя остановка на эпохе **36** (25 эпох без роста score после лучшей).

3. **Поздние эпохи.** К эпохе 20 метрики на val при 0.5 сильно портятся (например `val_auc≈0.32`, `val_acc=0.5`) — модель снова уходит в смещённые режимы; **чекпоинт по лучшему val AUC (эп. 11)** как раз отсекает эту деградацию.

4. **Калибровка.** При пороге **0.5** почти нет предсказаний класса 1 (вероятности занижены). Порог **Youden J ≈0.474** даёт разумный баланс: confusion на val `[[17,5],[2,6]]` — recall по «нецентральному» **0.75**, precision **0.55**; **в инференсе использовать сохранённый порог**, а не 0.5.

5. **Вывод.** Пайплайн после доработок ноутбука ведёт себя осмысленно: есть окно хорошей генерализации по AUC, затем переобучение/дрожание на малом val. Для сравнения с прогоном `sag_only_20260411_182037` (там AUC калибровки был ниже при другой инициализации) важно фиксировать **seed** и/или **K-fold** по пациентам.
