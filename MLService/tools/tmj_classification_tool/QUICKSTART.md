# TMJ Classification Tool - Quick Start

## Быстрый старт

1. **Запуск сервера:**
   ```bash
   cd MLService/tools/tmj_classification_tool
   ./start.sh
   ```

2. **Открыть в браузере:** http://localhost:8000

3. **Начать работу:**
   - Укажите путь к папке с пациентами
   - Нажмите "Сканировать"
   - Выберите исследование и начните разметку

## Основные возможности

### 🔍 Сканирование
- Автоматическое обнаружение DICOM исследований
- Поддержка вложенной структуры папок
- Определение метаданных (модальность, дата и т.д.)

### 🧹 Очистка файлов
- Удаление .exe, .dll, .jpg и других мусорных файлов
- Режим предпросмотра (dry run)
- Безопасная проверка DICOM перед удалением

### 🖼️ Визуализация
- **3 плоскости:** Аксиальная, Саггитальная, Корональная
- **Слайдеры** для навигации по срезам
- **Нормализация** изображений для оптимальной видимости
- **Canvas rendering** с поддержкой больших объемов

### 🏷️ Классификация
- Независимая разметка левого и правого сустава
- Динамическое добавление новых категорий
- Быстрый выбор тегов клавишами 1-9
- Автоматическое сохранение прогресса

### ⌨️ Горячие клавиши
- `←/→` - Навигация по срезам
- `1-9` - Выбор тега для левого сустава
- `Shift+1-9` - Выбор тега для правого сустава
- `Ctrl+S` - Сохранить
- `Ctrl+Enter` - Сохранить и следующее

### 💾 Хранение данных
- JSON формат для аннотаций
- Автоматическая загрузка при повторном запуске
- Отображение уже размеченных исследований
- Статистика по категориям

## Структура JSON аннотаций

```json
{
  "version": "1.0",
  "available_tags": ["normal", "osteoarthritis", "dislocation", "ankylosis"],
  "annotations": [
    {
      "patient_id": "11215",
      "study_id": "11215_20250425_2.16.840",
      "study_path": "/path/to/study",
      "left_joint_tag": "normal",
      "right_joint_tag": "osteoarthritis",
      "annotated_at": "2025-01-14T12:00:00",
      "annotated_by": "user"
    }
  ]
}
```

Файл сохраняется в: `MLService/data/tmj_classifications.json`

## API Endpoints

| Endpoint | Метод | Описание |
|----------|-------|----------|
| `/` | GET | Главная страница |
| `/annotate/{patient_id}/{study_id}` | GET | Страница разметки |
| `/api/scan_patients` | POST | Сканирование папки |
| `/api/clean_files` | POST | Очистка файлов |
| `/api/studies` | GET | Список исследований |
| `/api/study/{patient_id}/{study_id}` | GET | Загрузка исследования |
| `/api/slice/{patient_id}/{study_id}/{plane}/{index}` | GET | Получение среза |
| `/api/annotate` | POST | Сохранение аннотации |
| `/api/annotations` | GET | Все аннотации |
| `/api/tags` | GET | Доступные теги |
| `/api/add_tag` | POST | Добавить тег |

## Пример использования

1. **Запустить сервер:**
   ```bash
   ./start.sh
   ```

2. **Открыть http://localhost:8000**

3. **Указать путь к папке с пациентами:**
   ```
   /Users/tzopiz/Developer/MasterProject
   ```

4. **Сканировать** - найдет все DICOM исследования

5. **Опционально: Очистить файлы** (предпросмотр, затем очистка)

6. **Открыть любое исследование** из списка

7. **Просмотреть срезы** в 3 плоскостях

8. **Выбрать теги:**
   - Нажать кнопку категории для левого сустава
   - Нажать кнопку категории для правого сустава

9. **Сохранить** (Ctrl+S или кнопка)

10. **Сохранить и Далее** - вернуться к списку
