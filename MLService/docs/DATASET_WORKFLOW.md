# Workflow сбора датасета ВНЧС

Этот документ описывает процесс полу-автоматической разметки данных для сегментации ВНЧС.

## 1. Подготовка и Кроппинг

Мы используем скрипт `manual_crop_tool.py` для быстрого извлечения областей интереса (ROI) суставов из больших КТ-снимков.

### Запуск инструмента

```bash
# Активируем окружение
source MLService/venv/bin/activate

# Запускаем инструмент
python MLService/manual_crop_tool.py "путь/к/папке/с/DICOM" --output "data/processed_crops"
```

### Использование
1. **Навигация:** Используйте слайдер или стрелки Вверх/Вниз для перемещения по Z-срезам. Найдите срез, где сустав виден лучше всего (обычно середина суставной головки).
2. **Выбор Левого сустава:** Нажмите кнопку **"Set Left TMJ"**, затем кликните в центр левого мыщелка на изображении (на экране это правая сторона черепа пациента, и наоборот, но следуйте анатомической стороне или названию кнопки).
3. **Выбор Правого сустава:** Нажмите кнопку **"Set Right TMJ"**, затем кликните в центр правого мыщелка.
4. **Сохранение:** Нажмите **"Save Crops"**. Скрипт сохранит два файла `.nii.gz` (NIfTI) в указанную папку:
   - `ScanName_left.nii.gz`
   - `ScanName_right.nii.gz`

## 2. Разметка в ITK-SNAP

1. Скачайте и установите [ITK-SNAP](http://www.itksnap.org/).
2. Откройте сохраненный файл `.nii.gz`: `File -> Open Main Image`.
3. Перейдите в режим сегментации (Paintbrush Tool).
4. Создайте новый Label (Label 1, имя "TMJ").
5. Закрасьте область сустава.
   - Используйте 3D кисть для скорости.
   - Проходите по слоям, корректируя форму.
6. Сохраните сегментацию: `Segmentation -> Save Segmentation Image`.
   - Имя файла: `ScanName_left_mask.nii.gz` (обязательно суффикс `_mask`).

## 3. Структура данных

После разметки папка `data/processed_crops` должна выглядеть так:

```
data/processed_crops/
  ├── scan1_left.nii.gz       # Исходный кроп
  ├── scan1_left_mask.nii.gz  # Маска
  ├── scan1_right.nii.gz
  └── scan1_right_mask.nii.gz
```

Эти пары файлов будут использоваться для обучения модели.
