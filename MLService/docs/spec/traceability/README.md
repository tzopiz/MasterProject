# Трассировка MLService

TC определены рядом с требованиями; этот реестр связывает их с реализацией и проверками. Синтетические CPU-проверки подтверждают технический путь. Они не устанавливают качество моделей, независимость реальной когорты, клиническую применимость или успешность запуска на GPU.

[Технические записи](../../ai/README.md) фиксируют особенности реализации; [пробелы и решения](../open-questions/README.md) отделяют выполненную техническую приёмку от вопросов реальных данных. Команды воспроизведения и состав приватных артефактов: [исследовательский runbook](../../../google_colab/README.md). Публикуемые отчёты содержат агрегаты; хеширование идентификаторов не делает построчные результаты публичными.
