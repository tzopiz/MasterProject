# Локальные патчи MLService

PATCH-ML-* — локальная запись только о ранее не описанном поведении внутри
уже специфицированного API. TC-PATCH-ML-* — её проверяемая приёмка.
Это code-first исключение не меняет научные правила и не отменяет конституцию.

Патч допустим, если не меняет границу API, смысл данных, классы, группировку,
протокол оценки, внешние побочные эффекты или согласованный критерий приёмки.
Изменение любой из этих вещей требует обычного change до реализации.

Запись должна назвать исходное поведение, узкую разницу, источник в коде,
связанный FR/NFR, предусловие/действие/результат и фактический результат проверки.
Секреты и приватные примеры не добавляются. Новое требование переносится
в соответствующий нормативный раздел; патч не становится вторым контрактом.

Активных патчей в этой спецификации нет. Обнаруженные при аудите расхождения
находятся в [GAP-реестре](../open-questions/README.md), а не объявляются исправленными.
Общий формат — [шаблоны](../../../../docs/spec/templates/README.md).
