# MLService: спецификация исследования и инференса

MLService — самостоятельный логический компонент исследования ВНЧС по КЛКТ.
Он отвечает за подготовку ML-данных, локализацию, классификацию положения,
исследование сегментации и свой вклад в HTTP-инференс.

Спецификация задаёт требуемую семантику данных и научных выводов. Она не
объявляет все требования реализованными. Различия с проверенным кодом находятся
в [пробелах](open-questions/README.md); детали реализации — в [ai](../ai/README.md).

| Раздел | Что определяет |
|---|---|
| [Данные](functional/data/README.md) | Идентичность, метки, группировка, происхождение |
| [Локализация](functional/localization/README.md) | Стороны, координаты, ROI и оценка центров |
| [Классификация](functional/classification/README.md) | Задачи, разделение оценки и подбора, отчёт |
| [Сегментация](functional/segmentation/README.md) | Маски, совместимость обработки и границы выводов |
| [Нефункциональные требования](nonfunctional/README.md) | Воспроизводимость, приватность, безопасность |
| [Интеграция](integration/README.md) | ML-граница обмена с приложением |
| [Открытые вопросы](open-questions/README.md) | Доказанные расхождения и решения владельца |
| [Трассировка](traceability/README.md) | Навигация по требованиям и покрытию |
| [Патчи](patches/README.md) | Дополнительные правила нового поведения |

Общие правила принадлежат [корневой спецификации](../../../docs/spec/README.md):
[конституция](../../../docs/spec/constitution/README.md),
[соглашения](../../../docs/spec/conventions/README.md),
[глоссарий](../../../docs/spec/glossary/README.md) и
[шаблоны](../../../docs/spec/templates/README.md).
Для существенной функции можно добавить отдельный план по общим соглашениям.
Перед ML-запуском заполняется [протокол](../../experiments/template/README.md).

Численные результаты конкретных прогонов остаются в [реестре экспериментов](../../experiments/README.md).
Они не становятся нормативными порогами качества только из-за публикации отчёта.
