# MLService: технические записи

Это описание реализации clean-main на 2026-10-02, а не нормативная спецификация
и не отчёт нового эксперимента. Обучение, model loading, HTTP и tests не запускались.

- [Данные](data/README.md): join, идентификаторы и ограничения provenance.
- [Модели](models/README.md): три семейства детектора, ROI и маски.
- [Оценка](evaluation/README.md): выбор эпохи/порога и смысл метрик.
- [Инференс](inference/README.md): точный текущий HTTP-путь.

Требуемое поведение — в [spec](../spec/README.md). Приватная когорта,
локальные веса и непубликуемые отчёты не используются как публичные доказательства.
