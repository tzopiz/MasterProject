# MLService / services

Сервисный слой, вызываемый из **`app.py`**: загрузка DICOM, детектор, геометрия и сбор ответа для API.

## Модули (кратко)

| Файл | Роль |
|------|------|
| `detector_service.py` | Загрузка весов детектора, инференс по объёму. |
| `dicom_processor.py` | Чтение серии DICOM, построение 3D-массива. |
| `diagnosis_engine.py` | Сбор диагностического результата для ответа клиенту. |
| `geometry_calculator.py` | Пересчёты координат и размеров в пространстве снимка. |
| `slice_finder.py` | Вспомогательная логика по срезам / ориентации. |

Детали контрактов — в исходниках и в [../README.md](../README.md) (раздел API).
