# Models Directory

Эта директория предназначена для хранения файлов обученных моделей.

## Поддерживаемые форматы

- PyTorch (`.pth`, `.pt`)
- ONNX (`.onnx`)

## Размещение модели

1. Поместите файл модели в эту директорию
2. Установите переменную окружения `MODEL_PATH`:
   ```bash
   export MODEL_PATH=models/your_model.pth
   ```

## Требования к модели

Модель должна:
- Принимать на вход изображения размером 256x256 (1 канал)
- Возвращать бинарную маску того же размера
- Быть совместимой с PyTorch или ONNX Runtime

## Dummy Mode

Если модель не найдена, сервис работает в режиме "dummy":
- Генерируются тестовые маски (круглые регионы)
- Вычисляются случайные параметры в пределах нормы
- Полезно для тестирования без обученной модели

## Обучение модели

Для обучения модели сегментации ВНЧС:

1. Подготовьте датасет DICOM изображений с аннотациями
2. Используйте архитектуру U-Net (уже реализована в `segmentation_model.py`)
3. Обучите модель на вашем датасете
4. Сохраните веса модели:
   ```python
   torch.save(model.state_dict(), 'models/segmentation_model.pth')
   ```

## Примечание

Файлы моделей (`.pth`, `.pt`, `.onnx`) добавлены в `.gitignore` и не коммитятся в репозиторий из-за большого размера.
