# ML Service

Python FastAPI сервис для обработки DICOM файлов и ML инференса для анализа ВНЧС.

## Структура проекта

```
MLService/
├── app.py                      # FastAPI приложение
├── models/
│   ├── segmentation_model.py  # Модель сегментации
│   └── (модели .pth/.onnx)    # Файлы моделей
├── services/
│   ├── dicom_processor.py     # Обработка DICOM
│   ├── slice_finder.py        # Поиск срезов
│   ├── geometry_calculator.py # Вычисление параметров
│   └── diagnosis_engine.py    # Логика диагностики
├── utils/
│   └── image_utils.py         # Утилиты для работы с изображениями
└── requirements.txt           # Зависимости
```

## Установка

1. Создать виртуальное окружение:
```bash
cd MLService
python3 -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
```

2. Установить зависимости:
```bash
pip install -r requirements.txt
```

## Запуск

```bash
python app.py
```

Или с помощью uvicorn:
```bash
uvicorn app:app --host 0.0.0.0 --port 8001 --reload
```

Сервис запустится на `http://localhost:8001`

## API Endpoints

### Health Check
```
GET /health
```

Возвращает статус сервиса и информацию о загруженной модели.

### Model Status
```
GET /models/status
```

Проверяет статус загруженной ML модели.

### Process DICOM
```
POST /process
Content-Type: application/json

{
  "dicom_path": "/path/to/file.dcm",
  "task_id": "uuid"
}
```

Обрабатывает DICOM файл и возвращает результаты анализа.

## Конфигурация

Переменные окружения:

- `MODEL_PATH` - путь к файлу модели (по умолчанию: `models/segmentation_model.pth`)

## Модель сегментации

Сервис поддерживает работу с моделями PyTorch (.pth файлы).

Для использования собственной модели:

1. Поместите файл модели в папку `models/`
2. Установите переменную окружения `MODEL_PATH`
3. Модель должна быть совместима с архитектурой U-Net или вы можете модифицировать `models/segmentation_model.py`

## Режим работы без модели

Если модель не найдена, сервис работает в "dummy mode":
- Генерирует тестовые маски
- Возвращает случайные параметры в пределах нормы
- Полезно для тестирования интеграции

## Функциональность

### 1. Парсинг DICOM
- Загрузка DICOM файлов
- Извлечение 3D данных
- Получение метаданных

### 2. Поиск срезов
- Поиск ортогональных (аксиальных) срезов
- Поиск сагиттальных срезов
- Поиск фронтальных (корональных) срезов

### 3. Сегментация
- Сегментация ВНЧС на найденных срезах
- Постобработка масок
- Возврат результатов в base64 PNG

### 4. Геометрические вычисления
- Высота суставной ямки
- Высота суставной головки
- Ширина сустава
- Суставная щель
- Дополнительные параметры

### 5. Диагностика
- Анализ параметров
- Определение состояния (normal/minor_abnormality/abnormal)
- Генерация рекомендаций
- Расчет уверенности

## Зависимости

- **FastAPI** - веб-фреймворк
- **pydicom** - обработка DICOM файлов
- **PyTorch** - ML инференс
- **NumPy** - численные вычисления
- **scikit-image** - обработка изображений
- **OpenCV** - компьютерное зрение
- **Pillow** - работа с изображениями
