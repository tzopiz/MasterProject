Резюме на русском языке
В исследовании разработана система автоматизированного анализа височно-нижнечелюстного сустава (ВНЧС) по данным конусно-лучевой компьютерной томографии (КЛКТ) с использованием методов глубокого обучения. Система включает двухэтапный пайплайн: 3D сверточная нейронная сеть для локализации суставов на полном снимке и 3D U-Net для сегментации костных структур. Модель детекции обучена на наборе из 470 аннотированных КЛКТ снимков и успешно локализует оба височно-нижнечелюстных сустава на полных 3D снимках, обеспечивая точное определение области интереса для последующего детального анализа. Разработанная система интегрирована в мобильное iOS приложение и может быть использована для автоматической поддержки диагностики патологий ВНЧС.

Резюме на английском языке
The study developed an automated system for temporomandibular joint (TMJ) analysis using cone-beam computed tomography (CBCT) data with deep learning methods. The system includes a two-stage pipeline: a 3D convolutional neural network for joint localization on full scans and a 3D U-Net for bone structure segmentation. The detection model was trained on a dataset of 470 annotated CBCT scans and successfully localizes both temporomandibular joints on full 3D scans, providing accurate identification of regions of interest for subsequent detailed analysis. The developed system is integrated into a mobile iOS application and can be used for automated support of TMJ pathology diagnosis.

Цель исследования
Применение методов глубокого обучения для автоматической локализации и сегментации височно-нижнечелюстного сустава на 3D КЛКТ снимках с целью поддержки диагностики патологий ВНЧС.

Материалы и методы
В настоящее время в медицинской практике широко применяются методы искусственного интеллекта для анализа медицинских изображений [1, 2, 3]. В исследовании используется набор данных из 470 КЛКТ снимков с ручной аннотацией координат центров левого и правого височно-нижнечелюстных суставов. Для обработки данных применяется двухэтапный пайплайн: на первом этапе 3D сверточная нейронная сеть (TMJDetectorLarge) с архитектурой энкодер-декодер выполняет регрессию координат центров суставов на полном 3D снимке размером до 768×768×576 вокселей. Архитектура модели включает последовательные 3D сверточные блоки с батч-нормализацией, операциями пулинга и глобальным усредняющим пулингом, за которыми следуют полносвязные слои для регрессии координат. На втором этапе 3D U-Net выполняет сегментацию костных структур внутри вырезанных областей интереса размером 128×128×128 вокселей. Для обучения модели детекции применяется функция потерь L1 (Mean Absolute Error), оптимизатор Adam с адаптивным изменением скорости обучения и механизм ранней остановки. Оценка качества локализации выполняется по метрике MAE на валидационной выборке.

Результаты
По результатам обучения модели детекции TMJ на валидационной выборке система демонстрирует стабильную и надежную работу при локализации височно-нижнечелюстных суставов. Модель успешно определяет местоположение обоих суставов (левого и правого) на полных 3D снимках размером до 768×768×576 вокселей и возвращает координаты центров суставов и ограничивающие прямоугольники, что позволяет автоматически выделять области интереса для последующей сегментации и количественного анализа. Архитектура TMJDetectorLarge содержит 14.4 миллиона параметров и оптимизирована для работы на платформе Apple Silicon с использованием Metal Performance Shaders (MPS), обеспечивая эффективную обработку медицинских изображений. Система интегрирована в трехкомпонентную архитектуру: iOS приложение (Swift/SwiftUI), Backend сервер (Swift Vapor) и ML-сервис (Python FastAPI). Графики функции потерь демонстрируют стабильную сходимость модели в процессе обучения, что подтверждает корректность выбранной архитектуры и параметров обучения.

Заключение
Разработанная система глубокого обучения демонстрирует перспективность применения методов искусственного интеллекта для автоматической локализации и анализа височно-нижнечелюстного сустава по данным КЛКТ. Полученные результаты подтверждают возможность использования подобных систем в качестве инструмента поддержки принятия решений в стоматологической и челюстно-лицевой диагностике. Дальнейшее увеличение объема обучающей выборки, оптимизация архитектуры модели и применение методов аугментации данных могут способствовать повышению точности локализации до субвоксельного уровня (MAE < 50 пикселей).

Кратко о целесообразности выступления
Цель работы — ознакомление слушателей с современными подходами к автоматической локализации и сегментации анатомических структур на 3D медицинских изображениях с использованием методов глубокого обучения. Доклад представляет практический пример применения сверточных нейронных сетей для анализа КЛКТ снимков височно-нижнечелюстного сустава и демонстрирует интеграцию ML-моделей в мобильные медицинские приложения для поддержки клинической диагностики.
