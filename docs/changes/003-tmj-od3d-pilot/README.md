# 003 — Пилот TMJ-OD3D без новой врачебной разметки

Статус: in-progress. Дата: 2026-10-05.

## Цель и границы

Проверить возможность отдельного исследования костных изменений ВНЧС на
авторской разметке TMJ-OD3D V2. Пользователь одобрил пилот; запуск платных
ресурсов требует отдельного конкретного плана и подтверждения расходов.
Это не обучение положения сустава и не замена разметки положения.

Связанные требования: FR-ML-DATA-LABEL-SEMANTICS,
FR-ML-DATA-PATIENT-GROUP, FR-ML-DATA-DATA-PROVENANCE из
[контракта данных](../../../MLService/docs/spec/functional/data/README.md).
[Протокол](../../../MLService/experiments/tmj_od3d_feasibility_20261005/README.md).

## Приёмка

- Проверить публичный источник, версию, условия и фактическую структуру меток.
- Подтвердить расшифровку кодов первоисточником или зафиксировать блокер.
- Отделить прежнюю техническую пробу от новых наблюдений и клинической проверки.
- Определить воспроизводимую выборку, проверку приватности и условия обучения.
- Зафиксировать решение go/no-go; не выдавать план за выполненное обучение.

## План

1. Аудит метаданных и авторского описания, поиск codebook.
2. Если семантика подтверждена — ограниченная выборка изображений и оценка
   технической пригодности; иначе no-go до получения словаря.
3. Записать протокол следующего этапа, ограничения DataSphere и результаты.
4. Обновить навигацию и выполнить scripts/check_specs.py.

## Проверки и результаты

Шаг 1 выполнен: агрегаты CSV и публичное описание проверены, подтверждённый
codebook не найден. Шаг 2 заблокирован семантикой: новые изображения не
отбирались; исторические три пациента не выданы за новый пилот.
Шаг 3 выполнен в части протокола и решения no-go. Точная смета DataSphere
отложена до mapping и размерности входа; платные задания не запускались.
Шаг 4: навигация обновлена. Проверки: `python3 scripts/check_specs.py`,
`git diff --cached --check` и проверка локальных ссылок новых документов — PASS. Работа не объявлена done: обучение и анатомическая
пригодность не проверены.

## Уточнение цели 2026-10-05

Пользователь уточнил критерий: готовность означает, что остаётся только
запустить обучение. Отчёт и PR не являются завершением. Продолжаем поиск
словаря и независимо готовим технический путь; предположения о клинических
кодах не разрешены. Самостоятельная реализация, ревью и проверки поручены
агенту; промежуточное одобрение каждого PR не требуется.

Продолжение плана:

1. Проверить авторские JSON и дополнительные публичные материалы. Для
   технического осмотра допускается локальная приватная загрузка до 2 GiB,
   без paid cloud; лимит 2 MiB прежнего этапа больше не ограничивает этот этап.
2. По результату аудита существующего кода выделить минимальные адаптеры
   отдельного osseous target, не менять значение position labels.
3. Подготовить входы, группировку пациентов и проверяемый train/eval запуск;
   любые неизвестные клинические определения остаются обязательным gate.
4. Проверить реальные данные и синтетический smoke без дорогостоящего обучения,
   затем подготовить DataSphere plan с конкретными ресурсами и командами.

Подтверждённый словарь найден в авторском GitHub; прежний блокер снят.
Свежая проверка DICOM/JSON выявила sparse slice ranges, они отражены в
[подготовке](../005-od3d-preparation/README.md). Исполняемые задачи описаны в
[004](../004-od3d-intake/README.md), [006](../006-od3d-training/README.md),
[007](../007-osseous-cloud/README.md). Готовность всей когорты ещё не доказана.

Декомпозиция review: отдельные изменения intake, ROI, streaming, preflight,
train/eval, cloud и curation. На checkpoint объёма trainer разделён на consumer
preflight (+261 production, +148 tests) и training/report (+287 production,
+143/-1 tests). Streaming содержит +326 production и +318 tests; это единый
протокол загрузки/resume, проверяемый отдельно от остальных частей.
Документация и сгенерированные/private artifacts не маскируют размер кода;
общий monolithic PR реализаций не создаётся.

## Проверенная реализация и оставшаяся приёмка

Полный локальный ML suite: **585 passed in 41.01s**. На Python 3.12.14 /
Torch 2.6.0 CPU trainer/cloud: **44 passed in 6.69s**. Независимое ревью
устранило ошибки EOF resume, позднего сохранения frozen split и disclosure
validation support. Эти проверки не доказывают готовность реальных данных
или улучшение метрик. Источник временами отвечает HTTP 429; подготовка
возобновляется из приватного checkpoint с cooldown, без обхода ограничений.

Остаются полный EOF/1043 coverage, review всех source failures, явная курация,
real-data consumer preflight binary/multilabel и готовые immutable bundles.
После них потребуется только подтверждение конкретного платного запуска.
