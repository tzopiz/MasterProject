## 🎯 О проекте

### AI Doctor — интеллектуальная система анализа височно-нижнечелюстного сустава

**Цель проекта:** Автоматизация диагностики патологий ВНЧС с использованием искусственного интеллекта для анализа КЛКТ (конусно-лучевой компьютерной томографии) снимков.

**Проблема:** Ручной анализ 3D медицинских изображений требует значительного времени врача-рентгенолога и может быть субъективным.

**Решение:** Мобильное iOS приложение с ML-сервисом, которое автоматически:
- 🔍 Находит височно-нижнечелюстные суставы на 3D снимках
- 📊 Вычисляет геометрические параметры
- 🎯 Предоставляет точные координаты для диагностики
- 📱 Работает на мобильных устройствах

---

## 🏗️ Архитектура и технологии

### Трехкомпонентная система

```
┌─────────────┐         ┌──────────────┐         ┌─────────────┐
│   iOS App   │ ◄─────► │    Backend   │ ◄─────► │  ML Service │
│  SwiftUI    │   REST  │   Vapor      │   REST  │  FastAPI    │
│             │         │   SQLite     │         │  PyTorch    │
└─────────────┘         └──────────────┘         └─────────────┘
```

**iOS приложение (Swift/SwiftUI)**
- Интуитивный интерфейс для загрузки DICOM файлов
- 3D визуализация результатов анализа
- Отображение координат и bounding box суставов

**Backend (Swift Vapor)**
- REST API для управления задачами
- Хранение результатов в SQLite
- Интеграция с ML-сервисом

**ML Service (Python FastAPI + PyTorch)**
- 3D CNN модель для детекции TMJ (14.4M параметров)
- Обработка DICOM файлов
- Вычисление геометрических параметров
- Точность: MAE < 100px на валидационном наборе

### Ключевые возможности

✅ **Автоматическая детекция** — находит левый и правый TMJ на полном 3D снимке  
✅ **Точные координаты** — возвращает центр и bounding box суставов  
✅ **Мобильная платформа** — работает на iPhone и iPad  
✅ **Масштабируемость** — готово к обработке множественных пациентов

## 📊 Результаты и метрики

- **Модель детектора:** TMJDetectorLarge (3D CNN)
- **Датасет:** 37 аннотированных КЛКТ снимков
- **Точность:** Validation MAE = 97.34 px (цель: < 50px)
- **Архитектура:** U-Net для сегментации, 3D CNN для детекции
- **Платформа:** Apple Silicon (MPS) оптимизация
