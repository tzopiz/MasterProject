# Общие интеграционные соглашения

Этот файл связывает контракты участников, а не дублирует их реализацию. Согласованность относится к исходникам и описанному намерению; ни один статус здесь не сообщает о выполненной сквозной проверке.

<a id="int-mp-series-upload"></a>
## INT-MP-SERIES-UPLOAD — Передать серию и получить задачу

**Правило.** iOS передаёт выбранную серию Backend. Backend выдаёт идентификатор созданной задачи; дальнейшие обращения относятся к ней. Передача не должна незаметно терять часть выбранных файлов.

**Владельцы.** [iOS](../../../iOSApp/docs/spec/integration/README.md) владеет выбором/отправкой, [Backend](../../../Backend/docs/spec/integration/README.md) — приёмом/хранением и идентичностью задачи.

**Реализация.** Implemented-partial. Multipart и идентификатор есть; недоступные файлы на клиенте и ошибки записи/чтения на сервере могут быть пропущены. Согласованность: Divergent для полноты серии; совместимость сериализации multipart — Unverified.

**Доказательства и приёмка.** [Инженерный путь iOS](../../../iOSApp/docs/ai/README.md), [Backend](../../../Backend/docs/ai/README.md); сценарии и пределы покрытия — в прослеживаемости [клиента](../../../iOSApp/docs/spec/traceability/README.md) и [сервера](../../../Backend/docs/spec/traceability/README.md).

<a id="int-mp-inference"></a>
## INT-MP-INFERENCE — Получить исход вычисления для той же задачи

**Правило.** Backend передаёт серию и идентичность задачи в ML; возвращённый исход относится к этой задаче. Ошибка, несовпадающий идентификатор или результат, нарушающий согласованный формат, не должны становиться успешным анализом.

**Владельцы.** [Backend](../../../Backend/docs/spec/integration/README.md) проверяет ответ и сохраняет исход, [MLService](../../../MLService/docs/spec/integration/README.md) выполняет вычисление и описывает результат/ошибку.

**Реализация.** Implemented-partial. Используется регрессионная локализация; Backend не проверяет ML status/task_id как отдельные основания успеха. Согласованность: Divergent. Политика расширения файлов также расходится между путями.

**Доказательства и приёмка.** [Backend](../../../Backend/docs/ai/README.md), [ML](../../../MLService/docs/ai/README.md); проверки и пробелы — [Backend traceability](../../../Backend/docs/spec/traceability/README.md), [ML traceability](../../../MLService/docs/spec/traceability/README.md).

<a id="int-mp-localization-result"></a>
## INT-MP-LOCALIZATION-RESULT — Согласованно получить и отобразить локализацию

**Правило.** Клиент получает состояние и результат задачи через согласованный ресурс. Успешный результат сохраняет сторону, центры/границы и форму исходного массива; порядок осей и единицы одинаково понимаются всеми участниками. Повреждённый результат не объявляется успешным.

**Владельцы.** ML определяет семантику координат, Backend сохраняет её при передаче, iOS проверяет и отображает. Ссылки: [ML](../../../MLService/docs/spec/integration/README.md), [Backend](../../../Backend/docs/spec/integration/README.md), [iOS](../../../iOSApp/docs/spec/integration/README.md).

**Реализация.** Implemented-partial; согласованность Divergent. Клиентский путь polling отсутствует на Backend, бюджеты ожидания различаются, вложенное декодирование и длины массивов не защищают клиента от неполного результата. Система координат текущего ответа — воксели с порядком z/y/x; физическая ориентация и миллиметры не предоставляются.

**Проверка.** Доказательства в инженерных справочниках участников; сквозная приёмка по таблицам прослеживаемости остаётся неподтверждённой. Общий срок ожидания и восстановление задачи после прерывания требуют отдельного решения, а не выдуманного таймаута.

<a id="int-mp-research-boundary"></a>
## INT-MP-RESEARCH-BOUNDARY — Отделять исследование от доступной функции

**Правило.** Классификация, heatmap-кропы и сегментация не считаются подключёнными к приложению из-за наличия модели или ноутбука. Подключение требует согласованных входов/выходов, происхождения модели, приёмки и обработки отказов во всех затронутых компонентах.

**Владелец.** [MLService](../../../MLService/docs/spec/README.md) описывает исследовательскую возможность; Backend и iOS определяют предоставление и отображение при отдельном изменении.

**Реализация.** Граница между текущим регрессионным HTTP-путём и исследовательским контуром подтверждается кодом: Aligned. Статус подключения исследовательских этапов: Not-implemented. Независимое качество и численный порог принятия модели не следуют из этого статуса.
