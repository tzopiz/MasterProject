# Общие термины MasterProject

| Термин | Значение и граница |
|---|---|
| ВНЧС / TMJ | Височно-нижнечелюстной сустав; сторона описывает анатомическую принадлежность, а не позицию на экране |
| КЛКТ / CBCT | Конусно-лучевая компьютерная томография |
| Пациент | Человек, чьи повторные исследования и стороны являются зависимыми наблюдениями для оценки модели |
| Исследование | Конкретное обследование; метка не считается автоматически применимой к другому обследованию того же пациента |
| DICOM-серия | Набор связанных срезов и метаданных для построения объёма; произвольная папка файлов не доказывает целостность серии |
| Идентификатор серии | Ключ набора срезов в конкретном источнике; одинаковые номера разных источников не устанавливают связь пациентов |
| Задача анализа | Ресурс Backend с идентификатором и жизненным циклом; не идентификатор пациента и не ML-run |
| Локализация | Центры и bounding boxes суставов в объёме; не классификация положения и не диагноз |
| ROI / кроп | Выделенная область исходного объёма с известным происхождением; параметры получения относятся к версии данных |
| Сагиттальная / фронтальная метка | Положение в соответствующей плоскости; исходные коды и классы модели различаются, mapping принадлежит ML |
| Central / non-central | Бинарные классы положения; отсутствующая метка не принадлежит ни одному из них |
| Сегментация | Маска выделенной структуры; её наличие и качество проверяются отдельно от центров и классов |
| Воксель / физическая координата | Индекс в массиве и положение с физическими единицами — разные величины; переход требует геометрии исследования |
| Baseline модели | Метод сравнения на одинаковом протоколе; не гарантированная нижняя граница качества |
| Validation / test | Данные выбора модели/параметров и данные итоговой оценки; повторный подбор по test лишает его независимости |
| Run / эксперимент | Исполнение заранее описанного исследовательского протокола; документированный отрицательный результат тоже полезен |
| Checkpoint / версия модели | Конкретное сохранённое состояние плюс архитектура, preprocessing, mapping и происхождение; имя файла этого не заменяет |

Термины общие для трёх компонентов. Точные транспортные представления и текущие особенности реализации описаны в инженерных справочниках; термины не обещают доступности функции в приложении.
