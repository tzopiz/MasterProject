# Спецификация системы AI Doctor

MasterProject исследует анализ ВНЧС по КЛКТ и содержит прототип прикладного пути: выбор серии → задача анализа → локализация → показ результата. Классификация и сегментация развиваются в исследовательском ML-контуре; их наличие в коде не означает доступность результата в приложении.

## Владельцы поведения

| Компонент | Ответственность | Собственная спецификация |
|---|---|---|
| Backend | Приём серии, идентичность и состояние задачи, вызов ML, хранение и выдача результата | [Backend](../../Backend/docs/spec/README.md) |
| MLService | Подготовка данных, исследовательские протоколы, совместимость моделей, локализация в HTTP-пути | [MLService](../../MLService/docs/spec/README.md) |
| iOS | Выбор серии, обращение к Backend, ожидание и понятное отображение результата/ошибки | [iOSApp](../../iOSApp/docs/spec/README.md) |

## Общие части

- [Принципы](constitution/README.md) — границы ответственности и доказательств.
- [Правила ведения](conventions/README.md) — два порядка разработки, дополнения, ID и работа с расхождениями.
- [Глоссарий](glossary/README.md) — общий смысл данных и результатов.
- [Интеграция](integration/README.md) — договорённости между компонентами и ссылки на обе стороны.
- [Шаблоны](templates/README.md) — спецификация функции, план и дополнение по необходимости.

## Как читать состояние

Указанные в разделах требования задают поддерживаемое поведение или явно обозначенную цель. Неполнота реализации фиксируется как `GAP`, решение, которого ещё нет, — как `OQ`. Ни статус реализации, ни декларация маршрута не подтверждают фактический запуск, доступность окружения или качество модели.

В компонентах `docs/spec/` содержит правила и приёмку, `docs/ai/` — инженерную карту реализации и доказательства. Общие статьи не повторяют внутренние алгоритмы компонента. [Протоколы экспериментов](../../MLService/experiments/template/README.md) остаются отдельными записями исследования.
