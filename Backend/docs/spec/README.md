# Спецификация Backend

Backend принимает серию DICOM для анализа ВНЧС, ведёт задачу обработки,
передаёт серию ML Service и предоставляет клиенту состояние и локализацию.

## Область и статус

Это сервисная спецификация поддерживаемого сценария, сверенная с исходниками
на 2026-10-02. Код подтверждает наличие обработчиков, но не успешное выполнение.
Сервисы, миграции, HTTP-сценарии и тесты при подготовке не запускались.
Приёмочные сценарии задают проверяемый результат; их наличие не означает прохождение.
Расхождения реализации с поддерживаемым намерением отмечены `GAP-BE-*`.
Неопределённая продуктовая политика вынесена в `OQ-BE-*` и не считается требованием.
