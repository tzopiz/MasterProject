# Сбор датасета и разметка ВНЧС

## Приоритет
⚡ High

## Оценка времени
1 неделя

## Описание
Реализовать полу-автоматический workflow для сбора и разметки датасета ВНЧС из КЛКТ.

## Задачи
- [ ] Спроектировать и реализовать `manual_crop_tool.py`
    - [ ] Загрузка серии DICOM
    - [ ] 3-проекционная визуализация (Axial, Coronal, Sagittal)
    - [ ] Выбор центра суставов (клик мышью)
    - [ ] Экстракция кропов (размер 128x128x128)
    - [ ] Сохранение в формате NIfTI (.nii.gz) для ITK-SNAP
- [ ] Документировать процесс разметки
    - [ ] Инструкция по использованию кроп-тула
    - [ ] Инструкция для ITK-SNAP (кисть, экспорт)
- [ ] Подготовить датасет "Baranova A"
    - [ ] Извлечь 10 кропов (5 левых, 5 правых)
- [ ] Обновить `train.py` для поддержки пар NIfTI/Numpy (в данный момент только images/masks)

## Критерии приемки
- Инструмент успешно вырезает и сохраняет 3D объемы.
- Сгенерированные объемы открываются в ITK-SNAP.
- Процесс задокументирован в `DATASET_WORKFLOW.md`.
